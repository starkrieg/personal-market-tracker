## Personal Market Tracker

A simple tracker for market data meant for personal use

Extract market data from the websites you want.

Transform the raw data and load into a Postgres database.

Then serve the data with a service app.

### DataETL

An ETL structure based on Python scripts. Add your own tickets, write your own data processors, and load the data into Postgres.

### DataServer

A data serving application in Java, with it's own UI + support for external clients.
